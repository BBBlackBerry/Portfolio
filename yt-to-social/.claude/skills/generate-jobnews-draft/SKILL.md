# generate-jobnews-draft

このSkillは、Web検索で集めた**就活関連ニュース記事**と、固定YouTubeチャンネルの**動画字幕コーパス**を入力に受け取り、両者の関連度を判定したうえで、**すぐ投稿できる下書き（X / Threads）** を生成します。

> ⚠️ **このファイルは「対象チャンネルのブランド」に合わせて編集してください。**
> 以下はテンプレートです。チャンネル名・口調・ターゲット・NG事項を実際の運用に合わせて上書きしてください。

---

## 入力

呼び出し元（`server/jobnews/analyze.py`）から以下が渡されます:

- **チャンネル動画コーパス**: 1行1動画のJSON（`video_id` / `title` / `url` / `transcript_excerpt`）
- **就活ニュース記事**: `title` / `url` / `published` / `snippet` / `content`

## 出力

呼び出し元が指定するJSON Schemaに**厳密に**従って出力してください（`matched_video_id` / `relevance_score` / `relevance_reason` / `newsworthiness_score` / `news_summary` / `draft_x` / `draft_threads`）。説明文や前置きは不要、JSONのみ。

**関連度（`relevance_score`）の判定基準（ゆるめに判定する）:**
- 0.0〜1.0。ニュース記事のテーマが、ある動画で扱ったテーマ・対象視聴者・悩みと重なるなら、多少こじつけ気味でも積極的に「関連あり」と判定してよい。
- ジャンルや扱う悩み（就活・新卒採用・インターン・キャリア設計など）が同じ方向を向いていれば **0.5 前後**。動画の具体的な主張・手法・事例とニュースが噛み合えば **0.7 以上**。
- コーパス内のどの動画ともテーマが噛み合わなければ低くてよい。その場合は `matched_video_id` を null にする。

**注目度（`newsworthiness_score`）の判定基準:**
- 0.0〜1.0。**関連動画の有無とは独立**に、「そのニュース自体がチャンネルの視聴者（就活生・若手）にとってどれだけ共有する価値があるか」を評価する。
- 大手企業の採用方針変更・制度改正・選考スケジュールの動き・広く報道されている話題などは **0.6 以上**。ニッチ／一企業内の小さな話題は低め。
- 就活・キャリアと明らかに無関係なニュースだけ **0.3 未満**。

**`news_summary` は関連度・注目度に関わらず必ず記入する。**

**下書き（`draft_x` / `draft_threads`）を出すかの判断:**
- 関連動画があり関連度が高い → **動画ブリッジ付き**の下書きを生成（構成テンプレA）。
- 関連動画は無いが注目度が高い → 動画に触れない**単独投稿**の下書きを生成（構成テンプレB）。
- 関連度も注目度も低い → `draft_x` / `draft_threads` を**空文字**にする（`news_summary` だけ残す）。

## 戦略ドキュメント（絶対遵守）

### 1. ブランドポジション
- ターゲット: **就活生 / 新卒1〜3年目 / キャリアに悩む若手**
- ジャンル: **就活ノウハウ / 新卒採用トレンド / キャリア設計**
- 最終目的: チャンネル登録と信頼の獲得（教材・面談・コミュニティへの導線）

### 2. 媒体別の役割
| 媒体 | 役割 | 文体 | 文字数目安 |
|---|---|---|---|
| X | 速報性・専門家としての視点提示・拡散 | 断言・要点先出し・テンポ重視 | 140字以内推奨（280字上限） |
| Threads | 共感・対話・チャンネルへの導線 | 会話調・改行多め・寄り添う | 300〜500字 |

### 3. トーン＆マナー
- **不安を煽らない**: 「やばい」「手遅れ」ではなく「今からでも間に合う」「知っておくと有利」の角度で。
- **上から目線にしない**: 「教えてあげる」ではなく「一緒に考える」。
- **ニュースを自分ごとに翻訳する**: 制度・統計の話を「あなたの就活でどう動くべきか」に必ず落とす。
- **根拠を示す**: ニュースの出典（記事タイトル）に触れ、憶測と事実を分ける。

### 4. 投稿の構成テンプレ

#### 構成テンプレA：関連動画あり（動画ブリッジ付き）

**X 構成:**
- フック（1行目）: ニュースの要点を就活生視点で一言（例:「2026卒の採用、◯◯が前倒しに。」）
- 本文（2〜4行）: 何が変わるか / 就活生は何をすべきか
- ブリッジ: 関連動画への自然な言及（例:「この話、◯◯の動画で詳しく話してます」）

**Threads 構成:**
- 導入: 改行多めの柔らかい語りかけ（「最近こんなニュース見た人いるかな」）
- 解説: ニュースの中身を噛み砕く
- 共感／アドバイス: 「焦らなくていい。まずこれだけ」
- CTA: 「同じこと気にしてる人いたらいいね」「詳しくは概要欄の動画で」など軽いアクション

#### 構成テンプレB：関連動画なし（注目度の高い「ニュースまとめ」）

関連する動画が無いが注目度が高いニュースは、**動画には一切触れず**、ニュース単体で完結する投稿にする。

**X 構成:**
- フック（1行目）: ニュースの要点を就活生視点で一言
- 本文（2〜4行）: 何が変わるか / 就活生は何をすべきか（具体的な次の一手を1つ）
- 締め: 軽い一言（動画ブリッジやCTAは入れない。無理に登録誘導しない）

**Threads 構成:**
- 導入: 改行多めの柔らかい語りかけ
- 解説: ニュースの中身を噛み砕く（出典＝記事タイトルに触れる）
- 共感／アドバイス: 「焦らなくていい。まずこれだけ」
- 締め: 「同じこと気にしてる人いたらいいね」程度の軽いアクション（動画への導線は入れない）

### 5. ニュース→動画のブリッジ方法（構成テンプレA のときだけ）
- マッチした動画の `title` を自然に織り込む。動画URLそのものは下書き本文に貼らない（運用側が概要欄/リプで補う）。
- 「ニュースで話題 → でもチャンネルでは前からこう言ってた」という"先見性"の見せ方を優先する。
- 構成テンプレB（関連動画なし）では、存在しない動画をでっち上げて言及しない。動画には触れない。

### 6. NG事項（絶対に守る）
- ❌ 不安・煽り（「これを知らないと落ちる」等の脅し文句）
- ❌ ニュースの丸写し・コピペ（必ず自分の言葉で要約し、視点を加える）
- ❌ 出典のない断定（記事に書いていない数字・事実を作らない）
- ❌ 1投稿に複数メッセージを詰め込む（**1投稿1メッセージ厳守**）
- ❌ 政治的・センシティブな論評（事実の紹介に留める）
- ❌ ハッシュタグ乱用（X: 0〜1個、Threads: 0個）／絵文字乱用（1〜3個まで）

### 7. セルフチェック（出力前）
1. `draft_x` は140字前後に収まっているか
2. ニュースの事実と、こちらの解釈が混ざっていないか
3. 「就活生が次に取る行動」が1つ明示されているか
4. 構成テンプレAなら、マッチ動画とニュースのテーマが重なっているか（多少のこじつけは許容）。構成テンプレBなら、動画に触れていないか
5. `news_summary` を関連度・注目度に関わらず記入したか
